# papers/ — Artigos e Referências

> Leia este arquivo antes de criar ou modificar qualquer coisa nesta pasta.

## O que fica aqui

Toda a base bibliográfica da pesquisa:

- **PDFs** dos artigos científicos lidos (organize por autor ou tema)
- **`notes/`** — Anotações de leitura em Markdown, um arquivo por artigo
- **`READING_LIST.md`** — Lista de artigos a ler, lidos e rejeitados

## Convenção de nomes

```
papers/
├── READING_LIST.md
├── notes/
│   ├── autor2024-titulo-curto.md   ← anotações de leitura
│   └── ...
└── pdfs/
    ├── autor2024-titulo-curto.pdf  ← PDF original
    └── ...
```

## Template de anotação de leitura

Cada arquivo em `notes/` deve seguir esta estrutura mínima:

```markdown
# Título do Artigo

**Autores:** ...
**Publicado em:** VENUE ANO
**Link:** ...

## O que propõe
...

## Métodos principais
...

## Resultados relevantes
...

## Conexão com nosso trabalho
...

## Citação BibTeX
...
```

## O que NÃO fica aqui

- Anotações pessoais gerais → use seu Obsidian/Cerebro
- Código de reprodução → fica em `code/`
